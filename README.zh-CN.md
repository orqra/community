# Orqra 社区

Orqra 的公开反馈与更新入口，用于收集问题、讨论功能建议和维护版本更新公告。

Orqra 是一款本地优先的 AI 创意工作流桌面应用。你可以在画布中组织可复用的创作工作流，使用自己的 API Key 连接模型服务。

项目、工作流、提示词和结果保存在本机；运行模型时，请求与选定输入会发送给你配置的模型服务商。Orqra 不包含模型额度，第三方模型费用由你直接向服务商支付。

## 常用入口

- [Orqra 官网](https://orqra.com)：产品介绍、文档，以及当前开放状态和获取方式。
- [反馈问题或提出建议](https://github.com/orqra/community/issues/new/choose)：选择中文或英文表单。
- [查看已有反馈](https://github.com/orqra/community/issues)：提交前先搜索相似问题，并在已有讨论中补充信息。
- [版本更新公告](https://github.com/orqra/community/releases)：版本说明；实际可用版本和获取方式以官网为准。

这里维护公开信息和社区反馈，产品源码单独维护。

## 如何反馈

报告问题时，请提供 Orqra 版本、操作系统、复现步骤，以及期望结果和实际结果。提出功能建议时，请说明你想完成什么，以及目前遇到的困难。

**Issues 和附件对所有人公开。** 请勿上传 API Key、Token、License Key、个人资料、私有项目或含有敏感信息的日志与截图。需要私下处理的问题，请使用下方对应邮箱。

功能建议会作为产品改进参考，提交建议不代表已经承诺实现或排期。
