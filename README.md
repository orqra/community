# Orqra Community

The public home for Orqra bug reports, feature requests, and release notes.

Orqra is a local-first AI creative workflow desktop app. Organize reusable creative workflows on a canvas and connect your own model services using your API keys.

Projects, workflows, prompts, and results are stored on your computer. When you run a model, the request and selected inputs are sent to your configured model provider. Orqra does not include model credits; you pay third-party model fees directly to the provider.

## Useful links

- [Orqra website](https://orqra.com): product information, documentation, and current availability.
- [Report a bug or request a feature](https://github.com/orqra/community/issues/new/choose): choose an English or Chinese form.
- [Browse existing feedback](https://github.com/orqra/community/issues): search before posting and add useful details to an existing discussion.
- [Release notes](https://github.com/orqra/community/releases): version announcements. Refer to the website for available versions and how to get Orqra.

This repository hosts public information and community feedback. Product source code is maintained separately.

## Sharing feedback

For a bug report, include your Orqra version, operating system, steps to reproduce, and expected and actual results. For a feature request, describe what you want to accomplish and what is difficult today.

**Issues and attachments are public.** Do not upload API keys, tokens, license keys, personal information, private projects, or logs and screenshots containing sensitive information. Use the appropriate email below for matters that need private support.

Feature requests help inform product improvements. Submitting a request does not guarantee implementation or a release date.
