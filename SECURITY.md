# 安全漏洞报告 / Security reports

## 中文

如果你发现 Orqra 的潜在安全漏洞，请发送邮件至 [security@orqra.com](mailto:security@orqra.com)，通过私下渠道报告。

请勿在公开 Issues 中发布漏洞细节、利用代码或敏感数据。

尽量提供以下信息，方便定位问题：

- 受影响的 Orqra 版本、操作系统和功能。
- 问题描述、复现步骤及你观察到的影响。
- 不含敏感信息的示例或截图（如有）。

请使用测试数据复现。不要发送真实 API Key、Token、License Key、个人资料、私有项目文件或未脱敏日志。

一般使用、下载或激活问题请联系 [support@orqra.com](mailto:support@orqra.com)；购买或退款问题请联系 [billing@orqra.com](mailto:billing@orqra.com)。可以公开讨论的产品问题和功能建议，请使用 [Issues](https://github.com/orqra/community/issues/new/choose)。

## English

If you find a potential security vulnerability in Orqra, report it privately by emailing [security@orqra.com](mailto:security@orqra.com).

Do not post vulnerability details, exploit code, or sensitive data in public Issues.

Where possible, include:

- The affected Orqra version, operating system, and feature.
- A description, steps to reproduce, and the impact you observed.
- Examples or screenshots with sensitive information removed, if available.

Use test data to reproduce the issue. Do not send real API keys, tokens, license keys, personal information, private project files, or unredacted logs.

For general usage, downloads, or activation, contact [support@orqra.com](mailto:support@orqra.com). For purchases or refunds, contact [billing@orqra.com](mailto:billing@orqra.com). Use [Issues](https://github.com/orqra/community/issues/new/choose) for product problems and feature requests that can be discussed publicly.
